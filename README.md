# .NET Conf 2025
**Here are the official GitHub repositories connected to .NET Conf 2025:**

- 🔗 [dotnetconf GitHub Organization](https://github.com/dotnetconf/) — The **official GitHub org for .NET Conf**, hosting slides, branding, and shared content from the event. This is the central hub for all .NET Conf work.  
- 🔗 [mehrandvd/dotnetconf-full](https://github.com/mehrandvd/dotnetconf-full) — A **documentation repository** serving as the agenda and session catalog for .NET Conf 2025. It includes the main conference agenda (`README.md`) and a detailed session catalog (`sessions.md`) covering topics like **.NET 10, C# 14, Visual Studio 2026, and AI-powered development**.  
- 🔗 [.NET Conf Student Zone](https://microsoft.github.io/dotnetconf-studentzone/) — A **beginner-friendly pre-conference repo** designed to help students and newcomers get started with .NET. It includes follow-along projects and learning resources.  

---

### 📘 What You’ll Find Inside
- **Conference materials**: Slides, branding, and session recordings.  
- **Session catalog**: Organized by day, with details on talks about .NET 10, cloud-native development, AI integration, and modernization strategies.  
- **Learning resources**: Beginner projects and labs from the Student Zone.  

### 🚀 How to Use These Repos
1. **Clone the repo**: `git clone <repo-url>`  
2. **Explore agendas and session notes** to follow along with talks.  
3. **Check pinned repos** in the [dotnetconf org](https://github.com/dotnetconf/) for the latest year’s content.  
4. **Use Student Zone materials** if you’re new to .NET and want guided projects.  

These repositories are designed to help developers **continue learning after .NET Conf 2025**, whether you’re diving into **.NET 10 features**, experimenting with **AI-powered development**, or just starting out with C#.
